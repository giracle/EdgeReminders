# X / Twitter 线程

**推 1**

我做了一个 macOS 提醒事项 app：浮光提醒。

它是一片贴在屏幕边缘的玻璃，不占窗口。拖到边缘收起，鼠标停留展开。

原生 SwiftUI，开源，0.5.0 刚发布。

GitHub: github.com/giracle/EdgeReminders

**推 2**

按我自己的用法做了六个收集入口：

拖放（链接/文件/文字）、剪贴板自动收集、Ctrl+Shift+N 全局唤起、命令行 `er`、本地 HTTP 接口、快捷指令。

看到什么都能顺手扔进收件箱。

**推 3**

计划能力：标签、前置依赖（阻塞标记）、智能清单、自然语言搜索（`#面试` `明天` `紧急` 混打）、即将到期分组、子任务模板、重复事项。

该有的都有，不该有的都没加。

**推 4**

专注计时带日志：近 7 天时长/轮数、累计时长、活跃天数。专注时计时窗口下方有呼吸氛围光。

数据：CSV / Markdown / JSON 导出、整库备份恢复、统计页。

**推 5**

同步是手动 CloudKit：推到自己的私有 iCloud，另一台 Mac 拉回来。不传第三方服务器。

AI 拆子任务 / 周报走 OpenAI 兼容接口，Key 存钥匙串。

数据全在本地 JSON，零遥测。

**推 6**

macOS 15+，通用二进制，零第三方依赖。

DMG: github.com/giracle/EdgeReminders/releases
产品页: giracle.github.io/EdgeReminders/showcase/
