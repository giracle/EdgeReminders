# V2EX「分享创造」帖

**标题**：分享一个自己写的 macOS 贴边提醒事项 App：浮光提醒（开源，原生 SwiftUI）

---

最近一年我一直在找一个「不会打断我」的待办工具。大部分提醒事项应用都要占一个窗口，或者塞在菜单栏的小弹窗里，处理完一条要顺手关掉，来回几次人就烦了。

所以我写了浮光提醒：一个贴在屏幕边缘的玻璃浮窗。拖到任意边缘收起，鼠标停留自动展开，处理完再贴回去。它同时管 Apple 提醒事项和我自己定义的本机清单，拖进去的网页 / 文件 / 文字会直接变成待办。

## 已经有的功能

- **收集**：拖放、剪贴板自动收集、`Ctrl+Shift+N` 全局唤起、命令行 `er`、本地 HTTP 接口（127.0.0.1:8742）、快捷指令
- **计划**：标签、前置依赖（没做完的前置会让事项显示阻塞）、智能清单（标签/优先级/逾期/7 天内）、自然语言搜索（`#面试`、`明天`、`紧急` 混着打）、即将到期 14 天分组、批量选择、归档、撤销重做
- **专注**：番茄计时 + 普通倒计时，自动记日志统计（近 7 天时长轮数、累计、活跃天数），专注时计时窗口下方有呼吸氛围光
- **数据**：CSV / Markdown / JSON 导出、整库备份恢复、统计页（14 天完成柱状图）
- **同步**：手动 CloudKit 同步到自己的私有 iCloud（需要自己的开发者账号，临时签名版无法启用）
- **智能**：AI 拆子任务、AI 周报（Pro 演示码 `FUGUANG-PRO-2026`，支持 OpenAI/DeepSeek/Ollama 兼容接口）
- **视觉**：5 种主题色、面板透明度、完成事项烟花庆祝、彩虹细线

## 关于实现

原生 Swift / SwiftUI / AppKit，零第三方依赖，通用二进制（arm64 + x86_64），macOS 15+。数据全部是本地 JSON，不做任何遥测。

安装：GitHub Releases 下载 DMG，或仓库里的 Homebrew cask 本地安装。
