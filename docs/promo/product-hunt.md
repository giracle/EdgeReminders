# Product Hunt 发布文案

**Name**: 浮光提醒 · EdgeReminders

**Tagline**: A native macOS reminders app that docks to your screen edge

**Description**:

浮光提醒 is a menu-bar reminders app for macOS that lives on your screen edge as a piece of glass. Drag it to any edge and it tucks away; hover and it slides out. It manages both Apple Reminders and private local lists, and it accepts links, files, and text dropped straight into the float.

Everything is native (SwiftUI + AppKit), zero dependencies, universal binary, macOS 15+, and your data stays in local JSON — no telemetry.

**Highlights**:

- Edge-docking glass panel — never steals a window
- Capture anywhere: drag & drop, clipboard auto-capture, global hotkey, CLI (`er`), local HTTP API, Shortcuts/Siri
- Real planning: tags, prerequisite dependencies, smart lists, natural-language search, upcoming view, subtasks & templates, repeat rules
- Focus timer with logs and stats; ambient glow while focusing
- Data ownership: CSV / Markdown / JSON export, full backup & restore, optional manual CloudKit sync to your own private iCloud
- AI helpers (subtask breakdown & weekly report) via any OpenAI-compatible endpoint, keys stored in Keychain
