# 知乎回答 / 文章草稿

**问题**：有哪些好用的 macOS 提醒事项 App？

**回答**：

用了一圈提醒事项应用之后，我自己写了一个，叫浮光提醒（EdgeReminders，开源）。

它解决的是三个具体问题：

**一、提醒事项不应该占一个窗口。** 浮光提醒是一个贴在屏幕边缘的玻璃浮窗，拖到任意边缘收起，鼠标停留自动展开。写作、写代码的时候完全感觉不到它在，切回来处理完再贴回去。

**二、收集的摩擦要无限接近零。** 支持拖放（网页链接、文件、文字拖进浮窗就是一条待办）、剪贴板自动收集、全局快捷键、命令行 `er add`、本地 HTTP 接口、快捷指令。你在哪儿看到的东西，都能以最低成本扔进收件箱。

**三、计划能力要够用但不复杂。** 标签、前置依赖、智能清单（按标签/优先级/逾期聚合）、自然语言搜索（`#面试`、`明天`、`紧急` 可以混着打）、即将到期视图、子任务模板、重复事项。这些都在一个管理窗口里，不搞多层嵌套的项目管理。

另外还有：专注计时（带日志统计和氛围光）、CSV/Markdown/JSON 导出、整库备份、手动 CloudKit 同步、AI 拆子任务 / 周报（基于 OpenAI 兼容接口，Key 存在钥匙串）。

实现上是原生 Swift + SwiftUI + AppKit，零第三方依赖，通用二进制，数据是本地 JSON，没有遥测。

安装：GitHub Releases 下载 DMG，或 Homebrew cask。仓库：https://github.com/giracle/EdgeReminders
