**微博（带图 3 张）**

自己写了个 macOS 提醒事项 App，叫浮光提醒 ☕️

它是一片贴屏幕边缘的玻璃浮窗：拖到边缘收起，鼠标停留展开，不占窗口。能管 Apple 提醒事项和本机清单，拖个网页/文件进去就变成待办。还有标签、前置依赖、智能清单、自然语言搜索、番茄计时日志、导出备份、手动 iCloud 同步。

原生 SwiftUI，开源，macOS 15+，数据全在本地。

**小红书（标题 20 字内）**

标题：把待办贴在屏幕边缘的 macOS App

正文：
作为一个每天开十几个窗口的人，最烦的就是待办软件还要再占一个窗口。于是自己做了一个：浮光提醒。

▫️ 贴边浮窗：拖到屏幕边缘收起，鼠标停留展开
▫️ 五个收集入口：拖放、剪贴板、快捷键、命令行、本地接口
▫️ 计划：标签 / 前置依赖 / 智能清单 / 自然语言搜索
▫️ 专注计时：自动统计近 7 天专注时长和轮数
▫️ 数据：CSV、Markdown、JSON 导出，整库备份
▫️ 主题色 5 款，面板透明度可调

开源免费，macOS 15 以上都能用，芯片通用。
GitHub 搜「EdgeReminders」就能找到～
